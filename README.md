# اطلس سه‌بعدی طب سوزنی — دمو

دموی تعاملی و تک‌صفحه‌ای از یک اطلس سه‌بعدی نقاط دست. فارسی، راست‌به‌چپ، بدون build و بدون فریم‌ورک.

## اجرا روی سیستم خودتان

```
cd acupuncture-atlas
python3 -m http.server 8000
```

بعد `http://localhost:8000` را باز کنید.

به سرور ساده نیاز است چون ماژول‌های ES از مسیر `file://` بارگذاری نمی‌شوند؛ ولی به اینترنت نیازی نیست. Three.js، OrbitControls، GLTFLoader، رمزگشای Draco و فونت Vazirmatn همه داخل `vendor/` هستند.

## ساختار

```
index.html          کل برنامه: HTML، CSS، داده و منطق سه‌بعدی
vendor/three/       Three.js r169 و افزونه‌ها
vendor/fonts/       فونت Vazirmatn
assets/README.md    راهنمای جایگزینی مدل با یک فایل GLB
```

## چه چیزی را نشان می‌دهد

- مدل دست راست که به‌صورت رویه‌ای ساخته می‌شود؛ هیچ فایل مدل با مجوز نامعلومی همراه پروژه نیست.
- سه لایهٔ پوست، عضله و اسکلت با گذار نرم.
- ده نقطهٔ نمونهٔ دست به‌علاوهٔ یک ناحیهٔ نیمه‌شفاف سوجوک.
- جست‌وجوی فارسی با یکسان‌سازی «ی/ك»، نیم‌فاصله، ارقام فارسی و تحمل غلط تایپی. «هوگو»، `hegu`، `LI4` و «معده» همگی کار می‌کنند.
- حالت ادمین برای ثبت آزمایشی نقطه روی مدل و گرفتن مختصات از کنسول.
- پوستهٔ تیره و روشن، چیدمان موبایل‌اول.

## داده

نقاط داخل آرایهٔ `POINTS` در همان `index.html` هستند. هر نقطه این فیلدها را دارد:

```js
{ id, code, name_fa, name_en, location_fa, usage_fa,
  stimulation_fa, dos_fa, donts_fa, tags_fa: [...], position: [x, y, z] }
```

دادهٔ فعلی نمونه و تأییدنشده است. برای نسخهٔ واقعی باید جای آن محتوای بازبینی‌شدهٔ یک متخصص بنشیند.

## جایگزینی مدل

اگر `assets/model.glb` وجود داشته باشد به‌جای مدل رویه‌ای بارگذاری می‌شود. شرایط و قرارداد نام‌گذاری لایه‌ها در `assets/README.md` آمده است. بعد از تعویض مدل باید مختصات نقاط را با حالت ادمین دوباره تعیین کرد.

## انتشار

هر میزبان فایل ایستا کافی است؛ نیازی به Node، دیتابیس یا تنظیم سرور نیست. کل پوشه را آپلود کنید.

## هشدار

این یک ابزار آموزشی و نمونهٔ دمو است و جایگزین پزشک نیست. داده و جای‌گذاری نقاط تأیید بالینی نشده‌اند.
