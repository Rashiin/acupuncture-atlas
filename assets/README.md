# مدل اختیاری دست راست

این پوشه عمداً هیچ مدل آماده‌ای ندارد. مدل داخلی از هندسهٔ رویه‌ای تولید می‌شود و به دارایی دارای مجوز نامعلوم وابسته نیست.

برای کیفیت بهتر، یک مدل GLB رایگان را در assets/model.glb قرار دهید.
فقط مدلی را استفاده کنید که مجوز روشن برای کاربرد شما دارد؛ CC0 پیشنهاد می‌شود. رایگان بودن به‌تنهایی مجوز استفاده نیست.

## قرارداد مدل

- یک دست راست + ساعد، انگشتان به سمت +Y، کف دست رو به +Z، شست به سمت +X.
- مدل به ارتفاع ۵٫۵ واحد، با مرکز Y برابر با ‎−۰٫۱، استاندارد می‌شود.
- سه گروه یا مش با نام‌های skin، muscle و skeleton (یا bone) شناسایی می‌شوند. نام‌های فارسی پوست، عضله و استخوان نیز قابل استفاده‌اند؛ مش‌های بدون نام اختصاصی، پوست در نظر گرفته می‌شوند.
- اگر هر سه لایه موجود نباشند، مدل واردشده لایهٔ بیرونی است و عضله و استخوان داخلی به‌صورت رویه‌ای شبیه‌سازی می‌شوند. مدل‌هایی با تناسب متفاوت ممکن است با لایه‌های داخلی منطبق نباشند.
- روی سرور محلی کافی است فایل را در همین پوشه بگذارید. روی میزبان ایستا (مثل GitHub Pages) فهرست پوشه وجود ندارد، پس مسیر را صریح بدهید: `index.html?model=assets/model.glb` یا `data-model` روی تگ `<html>`.
- فشرده‌سازی Draco پشتیبانی می‌شود؛ تکسچرهای معمول را داخل GLB جاسازی کنید. برای سبک ماندن موبایل، تعداد چندضلعی و حجم تکسچر را محدود کنید.
- پس از تعویض مدل، مختصات نقاط را با حالت ادمین دوباره تعیین و از کنسول در آرایهٔ POINTS کپی کنید. هماهنگی خودکار آناتومیک انجام نمی‌شود.

## اجرا

از پوشهٔ حاوی index.html:

    python3 -m http.server 8000

سپس http://localhost:8000 را باز کنید. نصب وابستگی و مرحلهٔ build ندارد. Three.js، کنترل‌ها، رمزگشای Draco و فونت Vazirmatn همگی داخل پوشهٔ `vendor/` هستند، پس صفحه بدون اینترنت و بدون CDN هم کار می‌کند. فقط به یک سرور ساده نیاز دارد، چون ماژول‌های ES از مسیر `file://` بارگذاری نمی‌شوند.

دادهٔ نقاط، ناحیه و آناتومی همگی نمونه، تقریبی و تأییدنشده‌اند. هیچ دستور سوزن‌گذاری یا درمان در این دمو ارائه نمی‌شود. نقاط ادمین فقط در حافظهٔ همان صفحه می‌مانند و با بازخوانی پاک می‌شوند.
